# Netflix Web Demo 🎬

A simple Netflix-style movie web application built using FastAPI and Python.

## Features

- Netflix-style UI
- Movie cards display
- FastAPI backend
- JSON API endpoint
- Visitor counter
- HTML, CSS, JavaScript frontend

## Technologies Used

- Python
- FastAPI
- Uvicorn
- HTML
- CSS
- JavaScript

## Installation

Install required packages:

```bash
py -m pip install -r requirements.txt
```

## Run the Application

```bash
py -m uvicorn server:app --host 0.0.0.0 --port 8000 --reload
```

## Open in Browser

```bash
http://localhost:8000
```

## API Endpoint

```bash
http://localhost:8000/movies
```
